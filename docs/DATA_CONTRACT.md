# Data contract

All machine timestamps are ISO-8601 UTC strings. Apps Script displays dates in `Asia/Manila`. Emails are trimmed and lowercase for joins. Setup adds missing tabs/headers and never deletes rows.

| Tab                | Columns                                                                                                                                                                                                                                                                                                                                                              | Invariants                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Employees          | `employee_id,name,email,active,role_id,created_at,updated_at`                                                                                                                                                                                                                                                                                                        | unique normalized email; inactive is denied        |
| Roles              | `role_id,role_name,description,active,is_content_manager`                                                                                                                                                                                                                                                                                                            | stable role IDs                                    |
| RoleAssignments    | `employee_email,role_id,active,effective_from,effective_to`                                                                                                                                                                                                                                                                                                          | active/effective assignments only                  |
| FolderAccessMatrix | `role_id,route_key,folder_id,permission,active`                                                                                                                                                                                                                                                                                                                      | permission is `VIEWER` or `EDITOR`                 |
| MetadataFields     | `field_key,label,field_type,required,options_json,display_order,active,help_text`                                                                                                                                                                                                                                                                                    | stable unique key; ordered active configuration    |
| VettingQuestions   | `question_id,question_key,label,question_type,required,options_json,display_order,active,version,show_when_json`                                                                                                                                                                                                                                                     | historical responses retain version                |
| Routes             | `route_key,conditions_json,data_summary_spreadsheet_id,data_summary_tab,drive_folder_id,allowed_roles_json,active,version`                                                                                                                                                                                                                                           | one enabled match; IDs are authoritative           |
| VettingResponses   | `response_id,submission_id,question_id,question_key,answer,question_version,created_at,created_by`                                                                                                                                                                                                                                                                   | append-only historical answers                     |
| SubmissionRegistry | `submission_id,submission_version,idempotency_token,submitted_at,submitted_by,updated_at,updated_by,submission_type,route_key,target_sheet_id,target_sheet_tab,target_folder_id,validation_status,sheet_status,drive_status,acl_status,processing_status,attachment_count,retry_count,jira_issue_reference,last_error_code,last_error_message,completed_at,metadata` | one current registry row per stable ID             |
| SubmissionFiles    | `submission_file_id,submission_id,drive_file_id,original_filename,stored_filename,mime_type,size_bytes,folder_id,uploaded_at,uploaded_by,active`                                                                                                                                                                                                                     | original filename retained; Drive ID authoritative |
| AuditLog           | `audit_id,submission_id,event_type,actor_email,occurred_at,before_json,after_json,metadata_json,result,error_code`                                                                                                                                                                                                                                                   | append-only                                        |
| Settings           | `key,value,description`                                                                                                                                                                                                                                                                                                                                              | business settings only; no secrets                 |

Data Summary tabs contain `submission_id,submission_version,updated_at,updated_by` followed by every active `MetadataFields.field_key`. Missing tabs or headers are configuration errors; production submission never creates them.

Processing states: `RECEIVED`, `VALIDATING`, `VALIDATED`, `ROUTING`, `PROCESSING`, `FILES_SAVED`, `DATA_SAVED`, `COMPLETED`, `FAILED`, `PARTIAL`, `REQUIRES_REVIEW`, `CORRECTION_IN_PROGRESS`.

Error codes are stable: `AUTH_DENIED`, `VALIDATION_FAILED`, `FILE_VALIDATION_FAILED`, `ROUTE_NOT_FOUND`, `TARGET_SHEET_UNAVAILABLE`, `TARGET_TAB_UNAVAILABLE`, `DRIVE_FOLDER_UNAVAILABLE`, `DRIVE_UPLOAD_FAILED`, `SHEET_WRITE_FAILED`, `DUPLICATE_SUBMISSION`, `ACL_SYNC_FAILED`, `SUBMISSION_DELETE_FAILED`, `CONFIGURATION_ERROR`, `UNKNOWN_ERROR`.

`DELETED` is a terminal submission status. Deletion removes the routed Data Summary row, moves active Drive files to Trash, marks file rows inactive, and retains the Submission Registry and Audit Log records. A partially completed deletion remains `PARTIAL` and can be retried safely because completed removal steps are skipped.
